# OOPS Basic - Object Oriented Programming

**Procedural Programming** is aboout writing programs in procedure and methods, where **OOP** is about writing programs with objects created by class which holds method and data.

### Why?
- Easy to understand, debug
- Reliable
- Reusability (DRY - Don't Repeat Yourself)

## Object and Classes
1. Class is the template for the object. eg: Fruits
2. Object is the instance of the class. eg: Banana, Apple

## Class
- is the blueprint for an object to follow.
- contains methods, attributes to hold data.

## Methods 
refer - [Java Methods](./Methods.md)

## Attributes
- are the variables declared inside the class.

## Constructor
- is the method with the name of the class.
- this method gets executed when the object is created.
- i.e special method that is used to initialize objects.

## this Keyword
- this keyword is used to refer current object in a method or constructor
- when there is same attribute name existed inside the class's method, this keyword helps in differentiate the values.
