# Annotations.
**These does not add any functionality to the program, it just allow the compile to know additional information.**

## @Overrides

**This tells the compiler the method is getting overridden. So the compiler will throw error on the any wrong implementation.**

## @Deprecated
**This is to notify the other developers that the method is deprecates, so the developers can avoid the implementation.**

## @SupressWarnings
**This is to supress the warning thrown by the compiler. this is used in the legacy code to supress the waring. But it is a good habit to resolve the warnings.**
