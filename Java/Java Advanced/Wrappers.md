# Wrappers
**Are the inbuilt classes to handle the primitive data types. As Java does not support the primitive datatypes in the ArrayList operations.**

### Primitive Data Types and their respective Wrapper class:
    1. byte -> Byte
    2. short -> Short
    3. int -> Integer
    4. float -> Float
    5. char -> Character
    6. long -> Long
    7. double -> Double
    8. boolean -> Boolean

Wrapper classes have its own method to perform similar opeations.
``` code
intValue(), byteValue(), shortValue(), longValue(), floatValue(), doubleValue(), charValue(), booleanValue().
```
- toString() to convert the object to string.
